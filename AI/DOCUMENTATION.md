# Documentation responsibilities

AI/ is the durable project knowledge base for people and AI assistants.
Capture requirements, rationale, alternatives, open questions, research links,
implementation changes, commands, checks, and material limitations here.
MAIN.md stays concise; detailed information belongs in focused documents.
Update TODOS.md and LOG.md after meaningful work. Keep chronological log history.
Include enough context for a fork to proceed without access to the original chat.
Store only project-relevant information suitable for the open-source repository.
Executable code and installers live outside AI/; document and link them here.
