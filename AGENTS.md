# Contributor and AI instructions

Read AI/MAIN.md, AI/TODOS.md, and recent AI/LOG.md entries before working.
Keep discussion outcomes, requirements, decisions, research, setup details,
validation results, and handover notes in AI/. Update them as work progresses.
Record user requirements separately from proposals; do not silently promote a
proposal to an agreed decision. Preserve useful history and document scope changes.
Keep source code and executable operational scripts outside AI/, matching the
polar-web-app convention. Put every download/install operation in a reusable
installer script before executing it. Pin versions and verify archive checksums.
Do not commit secrets, signing keys, personal learning data, or machine-specific paths.
Maintain source attribution and redistribution permissions for learning material.
A fork must be understandable from committed files without this chat.
